11월 한 달 동안은 주로 이력서 / 자기소개서를 적을 예정입니다.
(물론 진행했던 프로젝트 유지보수 / 리팩토링 작업도 합니다)

이력서와 자기소개서는 구직시장에서 저를 표현하는 문서입니다만, 구직시장에서 말고 웹에서는 다른 방법으로 재밌게 표현하고 싶었습니다.

그래서 지금 보시고 계신 블로그를 업그레이드 및 수정하는 이야기를 적어볼려고 합니다.

## 블로그 간단 소개

### 기술

제 블로그는 정적 사이트를 제작하는데 특화된 [Astro](https://astro.build/) 웹 프레임워크로 만들어졌습니다. 마크다운 문법으로 제가 글을 쓰면 Astro에서 제가 미리 만든 템플릿으로 글이 적힌 페이지를 만들어줍니다.

왜 하필 다른 프레임워크가 아니라 Astro 였나면, Astro는 여러 UI 라이브러리를 함께 사용할 수 있는 구조여서 선택했습니다. 국내 프론트엔드 기술스택이 거의 React + Next.js로 통일 되었다고는 하지만, 다른 라이브러리도 적용해볼 수 있는 놀이터로 사용될 수 있으면 좋겠다는 마음에 선택했습니다.

배포 환경은 Github 레포지토리에 있는 코드를 빌드하고 배포해주는 [Netlify](https://www.netlify.com/)를 사용하고 있습니다. 그래서 글을 작성하고 커밋 + 푸시만 해준다면, 글을 웹에서 바로 볼 수 있습니다.
